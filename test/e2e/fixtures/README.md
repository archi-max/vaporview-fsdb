# e2e fixtures
- `counter.vcd`, `split_bits.vcd`, `cnt_names.*`: synthetic, written for these tests.
- `counter_fst.v` + `counter.fst`: synthetic; `counter.fst` generated with Icarus Verilog (`iverilog -o c counter_fst.v && vvp c -fst`).
- `wellen-ghdl/time_test.ghw`, `time_test.vhdl`: from wellen (https://github.com/ekiwi/wellen, `wellen/inputs/ghdl/`, commit 2ce18a4e73bd), BSD-3-Clause, see `wellen-ghdl/LICENSE`.
- `search.vcd`: synthetic (exact value search: 0x05, 0x15, 0x50, 0x55, 0x05, 0000x101, zzzz0101, 0xFB = -5, 0x05, 0x15).
- `reload_a.vcd`, `reload_b.vcd`: synthetic, auto reload (top.cnt = 0b101, then 0b111 at 0); the test copies one over the other (or their E2E_FORMAT twins).
- `link-extras/` (`xtb.sv`, `xtb.vcd`, `gen.py`): synthetic, generated by `gen.py` (packed arrays for Split > By Declared Dimensions; 61- and 141-signal instances for Add All Signals in Scope).
- `memword.vcd`: synthetic; memory words named `mem[12]`, `mem[13]` (a name with its index) next to a plain vector `vec[3:0]` (Add Variable by Path: the word vs a bit select).
